What the App Is

A logic puzzle game. The No-Guess mode generates boards that can be solved by deduction alone, so a correctly reasoned game never requires a coin flip. Retro mode is deliberately different: it uses original random generation, where an unavoidable guess can occur, because that is what the original game does.
